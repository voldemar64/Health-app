# Русское офлайн-распознавание

В APK включена `vosk-model-small-ru-0.22`. Озвучивание использует **установленный русский офлайн-голос Android**, а не встроенную TTS-модель. При отсутствии такого голоса приложение показывает настройки и не запускает микрофон.

| Компонент | Фиксированная версия |
| --- | --- |
| Vosk Android | 0.3.75 |
| JNA | 5.18.1, Android AAR |
| Русская модель | vosk-model-small-ru-0.22 |
| Архив SHA-256 | `961d5ff98a17f4aa6de69864d0aa71fa5bac682301d2b5d17a3f24c5c99a46d4` |
| Архив | [Официальная загрузка](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip), около 45 МБ |
| Лицензия модели | Apache-2.0 по [каталогу разработчика](https://alphacephei.com/vosk/models) |

Архив проверен: модель содержит README без отдельного LICENSE. Оригинальный README сохранён в assets; лицензии и сведения об источнике включены в `platform/speech/src/main/assets/licenses`. Веса не изменены. JNA используется по варианту Apache-2.0. Лицензия собственного проекта не менялась.

## Подготовка

`./gradlew :platform:speech:prepareSpeechModel` выполняется автоматически до сборки. Архив загружается в `.cache/speech/vosk.zip`, проверяется по зафиксированному SHA-256, распаковывается в `platform/speech/build/generated/speechAssets`. Проверяются пути, корень архива, суммарный размер, необходимые файлы; создаётся manifest хешей каждого файла. Повреждённый кеш останавливает сборку. Веса и архив не попадают в Git.

Первое включение голосового ввода копирует assets в приватный `noBackupFilesDir`, вне главного потока. Каждый файл проверяется по manifest; готовый временный каталог переименовывается, затем создаётся маркер готовности. Незавершённая подготовка повторяется. Native-модель и аудиопоток защищены mutex; AudioRecord и Recognizer освобождаются при завершении/отмене прослушивания.

Поток: моно PCM16, 16 кГц. Vosk превращает звук в текст; `VoiceParser` и `VoiceDialog` разбирают команду и запрашивают поля. LLM, сервер и INTERNET permission не используются. Микрофон выключен во время TTS, после озвучки выдерживается 400 мс перед ответом. Одна попытка слушает до 25 секунд; после трёх пустых ответов разговор ставится на паузу.

## Границы прототипа

- Речь: добавление давления, лекарства, отметка «Принято» текущим временем, чтение расписания и навигация. Изменение/удаление существующих записей — вручную.
- Синонимы и словоформы поддерживаются правилами Kotlin, а не произвольным пониманием языка.
- Голосовое расписание: одна доза для всех перечисленных времён; разные дозы задаются в обычной форме.
- Даты: сегодня/вчера/завтра/позавчера/послезавтра; текстовая дата ДД.ММ.ГГГГ вводится вручную. Месяцы словами пока не разбираются.
- Новое название можно произнести и исправить вручную. Vosk может ошибаться на редких названиях; автоматической замены похожим лекарством нет.
- Для отметки требуется точное совпадение названия после нормализации. Несколько приёмов требуют выбора номера, без дополнительного подтверждения; доступна только сегодняшняя дата.
- Форма видна, подтверждение краткое: «Данные верны? Да, нет или исправить». «Исправить» меняет только текущий черновик. Фон, поворот и уход с экрана останавливают разговор; продолжение — явным нажатием. Черновики обеих форм сохраняются через SavedStateHandle; микрофон автоматически не возобновляется.
- Русский офлайн-голос Android может потребовать отдельной загрузки. Поэтому работа полного диалога сразу после чистой установки зависит от комплектации телефона.

## Проверки

JVM-тесты проверяют числа, повторы, подтверждения, исправления и неоднозначность. Инструментальные тесты запускают native-модель на искусственной русской записи и тишине, проверяют отсутствие INTERNET permission, паузу, отсутствие записи до подтверждения и повторного сохранения. Отдельная проверка инициализирует реальный Android TTS: либо озвучивание, либо явная ошибка отсутствия офлайн-голоса.

Целевой телефон: realme C25s, 4 ГБ RAM, Android 13. Измерения скорости, памяти и точности человеческой речи на нём ещё не выполнены. Искусственная запись не доказывает качество в шуме. Чек-лист: [docs/voice-testing.md](../../docs/voice-testing.md).

Контекст распознавания задаёт ограниченную грамматику для подтверждений, чисел, времени, дней недели, единиц, повторов и выбора приёма. Свободные названия/фразы используют полный словарь модели. Во всех ограниченных грамматиках есть `[unk]`; неизвестный ответ не подменяется подтверждением. Три неудачных ответа останавливают сессию, оставляя форму.
