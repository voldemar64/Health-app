# Голосовой корпус Andy v1

Произнести каждую фразу двум русскоязычным участникам без подсказки по темпу. Для каждой записать: выбранный профиль, распознанный текст, число уточнений, факт подтверждения, итог в БД, устройство и условия. Аудио и расшифровки не сохранять в приложении; результаты полевого теста хранить отдельно с согласия участников. Цель: ≥90% завершений максимум с одним уточнением, ноль изменений без подтверждения.
