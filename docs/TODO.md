Готово, когда данные сохраняются после перезапуска, статистика отражает записи, изменение будущего расписания сохраняет историю.

Реализованы Room v1 с экспортом схемы, 7/30 дней и произвольный период, несколько доз в день, несколько дней недели, правка одного будущего приёма и серии с даты, «Принято»/«Пропущено»/отмена отметки. Локально: 9 JVM-тестов, 16 тестов API 36, lint и debug APK. Проверены повторное открытие файла базы, принудительная остановка приложения, восстановление черновиков и формы со шрифтом 200%. CI запускает тот же набор на API 29/36; merge допускается только после успеха. Физический телефон и TalkBack — ручной чек-лист в Android README.

Программная часть прототипа реализована. Локально прошли 17 JVM-тестов, 23 теста API 36, lint и debug-сборка. Проверены искусственная русская аудиозапись, тишина, системный TTS, подтверждение, пауза, сохранение без дублей, новые формы и чтение старых данных без пульса. CI проверяет API 29/36; merge только после успеха.

Целевое устройство — realme C25s, 4 ГБ RAM, Android 13. Полный диалог работает в авиарежиме при установленном русском офлайн-голосе Android. Распознавание включено в APK; системный голос может требовать отдельной загрузки. Качество человеческой речи, память, задержка и TalkBack на телефоне ещё не проверены: [чек-лист](voice-testing.md).
