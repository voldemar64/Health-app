Готово, когда проект собирается с чистого checkout в CI, приложение запускается на эмуляторе и показывает обе вкладки.

Локально на Windows проверены сборка, lint и пять UI-тестов API 36. CI проверяет Linux-сборку и устройства API 29/36; merge допускается только после успешных проверок. Крупный текст и светлая тема проверены на снимках эмулятора. Ручная проверка физического телефона и TalkBack остаётся по чек-листу Android README.

## Данные и ручной ввод

- [x] Измерения, статистика и график давления.
- [x] Названия лекарств, точные количества и единицы.
- [x] Однократный, ежедневный и еженедельный повтор.
- [x] Просмотр сегодня / неделя / месяц.
- [x] Ревизии расписания и отдельные факты приёма.
- [x] Проверки хранения, календаря и отсутствия дублей.

Готово, когда данные сохраняются после перезапуска, статистика отражает записи, изменение будущего расписания сохраняет историю.

Реализованы Room v1 с экспортом схемы, 7/30 дней и произвольный период, несколько доз в день, несколько дней недели, правка одного будущего приёма и серии с даты, «Принято»/«Пропущено»/отмена отметки. Локально: 9 JVM-тестов, 16 тестов API 36, lint и debug APK. Проверены повторное открытие файла базы, принудительная остановка приложения, восстановление черновиков и формы со шрифтом 200%. CI запускает тот же набор на API 29/36; merge допускается только после успеха. Физический телефон и TalkBack — ручной чек-лист в Android README.
