# Дневник здоровья · Andy v1 test

Локальное Android-приложение для давления, личных лекарств, приёмов и напоминаний. Интерфейс и голосовые команды на русском. Данные каждого профиля остаются в `health.db`; облачной синхронизации и сервера нет. Каталог лекарств и поиск аптек отложены.

## Сборка

Windows PowerShell из корня репозитория:

```powershell
. ./scripts/android-env.ps1
./apps/android/gradlew.bat -p apps/android --offline test lint assembleDebug assembleDebugAndroidTest
```

JDK 21, Gradle 8.13, AGP 8.13.2, Kotlin 2.3.10. `minSdk 29`, `compileSdk/targetSdk 36`, `applicationId io.github.voldemar64.healthapp`. Модули: `app`, `core/domain`, `core/data`, `platform/speech`, `platform/reminders`. Android Studio для сборки не требуется. Начальную установку инструментов выполняет `./scripts/setup-android.ps1`.

Готовый тестовый APK: `app/build/outputs/apk/andy-v1-test.apk`. Он подписан существующим локальным ключом прототипа, а не временным ключом CI. Перед установкой проверьте отпечаток сертификата по `.github/android-signing-cert.sha256`; файл ключа хранится вне Git. Команда локального выпуска описана в [docs/releases.md](../../docs/releases.md).

## Обновление с сохранением истории

1. Сохраните имеющийся APK и резервную копию данных устройства до обновления. Автоматическое резервирование приложения отключено; удаление приложения удалит `health.db`.
2. Сверьте `applicationId` и подпись нового APK со старой установкой. Подписанный тестовый APK использует прежний сертификат с SHA-256 `deefd167970dc0828a28710a97c6fc2ec3f258ce95474e697d7f268152f36b3b`.
3. Установите поверх, без удаления: `adb install -r apps/android/app/build/outputs/apk/andy-v1-test.apk`.
4. Откройте приложение. Старые записи окажутся в профиле «Основной»; переименуйте его при необходимости. Проверьте давление, графики, PDF, расписания, отдельные изменения приёмов.

Миграции Room явные: `1→2` добавляет профиль и источник давления, `2→3` создаёт личные карточки лекарств, слоты, журнал остатков и напоминания, `3→4` добавляет снимок дозировки приёма и данные уведомлений, `4→5` сохраняет монотонный срок таймера и счётчик загрузок. Схемы v1–v5 лежат в `core/data/schemas`. Исторические мг/г не переводятся в таблетки; прошлые приёмы не списывают остаток задним числом. Форма, дозировка и запас старой карточки остаются неизвестными. Откат приложения с базой v5 требует старый APK **и** копию БД до обновления.

## Проверка на устройстве

- Выберите/создайте два профиля. Запишите одинаковое название лекарства и давление в обоих; история, график и PDF должны отличаться.
- Проверьте давление без пульса, заметку и явное подтверждение необычного порядка чисел.
- Создайте карточку лекарства, ежедневное и недельное расписание, измените один будущий приём и схему с будущей даты. Старые факты сохраняют название и количество.
- Укажите запас 30, подтвердите приём 0,5, отмените: баланс 29,5 → 30. Сверка задаёт новый фактический отсчёт; при неизвестном или неточном балансе прогноз скрыт.
- Разрешите уведомления и точные сигналы. Проверьте разовое напоминание, «Принял», «Отложить на 15 минут», «Пропустить», просрочку 60 минут, перезагрузку и смену часового пояса. При отказе в разрешении настройки показывают ограниченный режим.
- Проверьте русский офлайн-TTS, голосовое подтверждение каждой записи, переключение профиля, таймаут, TalkBack и шрифт 200%.

Инструментальные тесты используют отдельную базу и могут запускаться на изолированном пакете `.qa`: `./apps/android/gradlew.bat -p apps/android -PisolatedTests=true :app:connectedDebugAndroidTest`. **После этого** соберите обычный APK без `-PisolatedTests=true`: тестовый пакет имеет другой `applicationId`. Не ставьте QA-пакет поверх телефона с личной историей.

Текущий статус проверок и ограничения: [Andy v1 verification](../../docs/andy-v1-verification.md). Голосовые фразы: [корпус](../../docs/voice-corpus.md). Архитектура: [docs/architecture.md](../../docs/architecture.md).

## Приватность

`health.db` находится в приватном хранилище. Manifest отключает backup; правила извлечения исключают приватные области. PDF создаётся по запросу через системный выбор файла. Звук и постоянная расшифровка не сохраняются. Технические логи не содержат значения измерений или названия лекарств.
