# Health App

Android-приложение на Kotlin: дневник давления, расписание лекарств и голосовой ввод на русском языке. Измерения, расписание и распознавание речи работают локально на телефоне.

Реализованы ручной ввод давления, график и средние значения, расписания лекарств с несколькими дозами, календарь и отметки приёма. Данные сохраняются локально в Room. Добавлен голосовой прототип: Vosk внутри APK, системный русский офлайн-голос Android, голосовой ввод внутри формы с короткими уточнениями и подтверждением «да / нет / исправить». Добавлен локальный PDF-отчёт за 7/30 дней. Уведомления — следующий этап. Инструкции запуска и проверки — в [Android README](apps/android/README.md).

## Первая версия

- Давление: история, графики давления и пульса за 7/30 дней, PDF-отчёт; общий «+» открывает форму с двумя вкладками.
- Лекарства: календарь недели/месяца, карточки лекарств, отметка «Принято» текущим временем; однократный, ежедневный и еженедельный приём.
- Голос: готовая модель на телефоне, разбор команд на Kotlin, подтверждение перед сохранением.
- Хранение: Room. Сервер, аккаунт и синхронизация для этих сценариев не требуются.
- Напоминания: отдельный Android-модуль; включаются после реализации расписания.
