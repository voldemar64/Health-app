# Health App

Android-приложение на Kotlin: дневник давления, расписание лекарств и голосовой ввод на русском языке. Измерения, расписание и распознавание речи работают локально на телефоне.

Репозиторий находится на этапе проектирования. Архитектура и границы модулей описаны; Android-приложение, Gradle-сборка и подключение весов ещё не реализованы.

## Структура монорепозитория

```text

  android/                 # Android-приложение и его будущие Gradle-модули

  decisions.md             # Решения и условия их пересмотра
  TODO.md                  # Этапы реализации и критерии проверки

```

## Первая версия

- Давление: история, график, статистика и одна кнопка добавления измерения.
- Лекарства: сегодня, неделя, месяц; однократный, ежедневный и еженедельный приём.
- Голос: готовая модель на телефоне, разбор команд на Kotlin, подтверждение перед сохранением.
- Хранение: Room. Сервер, аккаунт и синхронизация для этих сценариев не требуются.
- Напоминания: отдельный Android-модуль; включаются после реализации расписания.
